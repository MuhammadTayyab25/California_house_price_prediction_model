# 🏠 California House Price Prediction Using Machine Learning

## 📌 Project Overview

California House Price Prediction is a Machine Learning regression project that predicts house prices based on various housing features.

The model analyzes factors such as location, population, median income, number of rooms, households, and other housing characteristics to estimate the median house value.

This project demonstrates an end-to-end Machine Learning workflow including data exploration, preprocessing, feature engineering, model training, evaluation, and deployment.


---

# 🎯 Problem Statement

Accurately predicting real estate prices is a challenging task because housing prices depend on multiple factors such as location, income level, population density, and property characteristics.

This project uses Machine Learning regression algorithms to build a predictive model that can estimate house prices based on historical housing data.

Dataset Used:

**California Housing Dataset**


The dataset contains information about housing districts in California.

Features include:

- Median Income
- House Age
- Average Rooms
- Average Bedrooms
- Population
- Average Occupancy
- Latitude
- Longitude
